# Archive

Documents from the earlier phase of ConsciousMind (September to early October 2026), moved here unchanged so the repository root
describes the current Morals and Ethics work. Nothing was deleted; history is in git.

| File | What it is |
|---|---|
| `earlier_work/PROJECT_STATUS.md` | Status of the earlier "human-advantage benchmark" (Theory of Mind + counseling categories, 250 items) |
| `earlier_work/DATASET_SUMMARY.md` | One-page summary of that earlier dataset |
| `earlier_work/HANDOFF.md` | Work log of the earlier phase (ends with a pointer to the Morals and Ethics handoff) |
| `earlier_work/RESEARCH_NOTES.md` | Literature review and reasoning trail of the earlier phase |
| `earlier_work/ConsciousMind_Dataset_Progress.pdf` | Earlier progress PDF |

The data and code of that phase stay where they were, untouched, because their scripts use relative paths:
`dataset/category_a_theory_of_mind/`, `dataset/category_b_deflection_under_severity/`, `dataset/category_b_safety_judgment/`,
`dataset/build_dataset.py`, `dataset/build_dataset_full.py` and the copied reference repositories in `reference/`.
