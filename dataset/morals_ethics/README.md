# Morals & Ethics dataset (`morals_ethics_25k.csv`)

25,000 unique moral/ethical scenarios for the ConsciousMind project. Every *sourced* row comes from a published dataset; a small, clearly
separated synthetic set (written by Claude in this project) fills the applied-ethics gap. Built 2026-10-13.

| | |
|---|---|
| Rows | 25,000 (0 exact duplicates, 0 hard validation failures - see `DATA_QUALITY_REPORT.md`) |
| From published datasets: human-authored 20,534; author-written 347; LLM-generated *by the source authors* and published by them 2,621 | 23,502 |
| Synthetic, generated in this project (`is_synthetic=True`, never labeled) | 1,498 |
| With a human-derived label | 20,666; author/design-designated label 802; unlabeled open dilemmas 3,532 |
| Prior workbook items preserved with original ids | 416 / 416 (`data/CM_Ethics_Dataset_1.xlsx`, untouched) |

"25,000" is a count of distinct, structurally valid records. It is **not** a claim that 25,000 items are human-validated:
only the "human_labeled" rows carry human-derived labels, and none of the labels should be read as ground-truth moral correctness.

## Schema (one row = one item)
`item_id`, `origin` (`human_authored` | `author_written` | `llm_generated_published` | `synthetic_this_project`), `is_synthetic`,
`source_dataset`, `source_component`, `source_item_id`, `source_split` (the source's own split), `split` (our cluster-aware train/dev/test),
`task_type`, `domain`, `topic_tag`, `ethical_framework`, `scenario_text`, `question_text`, `response_format`, `answer_options` (`|`-separated),
`label` (as presented, i.e. option text/letter), `label_raw` (original value from the source), `label_type`, `human_label_status`,
`label_transform` (every mapping applied to the original label), `label_distribution` (JSON; vote/option counts the source publishes),
`n_annotators`, `label_agreement` (only numbers the source itself publishes or implies), `adversarial_filtered`, `near_dup_cluster_id`,
`near_dup_cluster_size`, `text_chars`, `n_prior_model_responses`, `preserved_from_prior_workbook`, `extra` (JSON: source-specific annotations
such as Social Chemistry rules-of-thumb and moral foundations, MoralChoice rule-violation labels, DailyDilemmas value tags, PhilPapers option
distributions), `license`, `citation`, `source_url`, `contamination_risk`, `validation_status`.

`label_type` values: `human_consensus`, `human_vote_plurality`, `human_annotation` (single annotator), `human_survey_plurality`,
`human_proportion_thresholded`, `human_majority_from_published_studies`, `author_designated`, `dataset_design_intended`, `none`.
Option order is shuffled (seeded by item id) wherever the source encodes the answer positionally (ETHICS virtue/utilitarianism, Scruples dilemmas, MoralChoice, BIG-bench) so labels are not position-biased.

## Sources (details/licenses in `output/source_manifest.csv`)
ETHICS (Hendrycks et al.; commonsense, justice, deontology, virtue, utilitarianism) - Scruples anecdotes and dilemmas (Lourie et al.) -
Social Chemistry 101 (Forbes et al.) - DailyDilemmas (Chiu et al.) - MoralChoice (Scherrer et al.) - MoralExceptQA (Jin et al.) -
BIG-bench simple_ethical_questions - PhilPapers 2020 survey (16 questions, from the prior workbook).
Hugging Face, Zenodo, arXiv, and Berkeley hosts are blocked in the build sandbox, so only GitHub / Google-Storage copies were used.
ETHICS data comes from the GitHub mirror `christian-machine-intelligence/psalm-alignment` (the same mirror the prior workbook used); all 400 prior
ETHICS items were checked against it and match text and label.

**Reviewed and excluded:** BIG-bench `moral_permissibility` (vignette/question mismatches in the source, heavy templating, no raw scores);
Moral Stories, MIC, Delphi/Commonsense Norm Bank, ValuePrism, Moral Machine, MFRC, ProsocialDialog (hosts unreachable from the sandbox - a possible
extension from a networked machine); ETHICS `cm_ambig` (unlabeled); Scruples `train-extra` (different annotation regime); Social Chemistry
rows flagged `rot-bad`, not tagged morality-ethics, or whose action is not performed by a character in the situation.

## Method
1. `fetch_sources.py` clones/downloads sources, pins commits and archive hashes (idempotent, never overwrites).
2. `stage_sources.py` runs one adapter per source into `work/staged/*.jsonl` (resumable; malformed rows -> `logs/stage_failures.jsonl`).
3. `build_dataset.py` validates rows, removes exact duplicates (preserved items win), drops items whose duplicates carry conflicting source labels, over-selects per-source candidates by label/split-balanced stratified sampling, clusters near-duplicates (MinHash, 3-word shingles, Jaccard >= 0.8; keep <= 2 per cluster), keeps one Social Chemistry item per situation, assigns train/dev/test (70/10/20) **by cluster**, and writes everything.
4. `validate_and_report.py` re-checks the shipped CSV independently (labels, enums, duplicates, JSON cells, near-duplicate leakage across splits) and writes the report.

Quotas are in `build_dataset.py` (`WEIGHTS`): small datasets are taken whole; the large ones share the remainder with fixed weights so no single benchmark dominates.

### Synthetic set (1,498 items, `include_synthetic=true`)
Published datasets contain almost no applied/professional ethics, so 12 domains x 5 sub-topics x 25 scenarios were requested
(`synthetic_spec.json`, `synthetic_prompt.md`); 2 of 1,500 were rejected by the answer-leak filter. They were written by 12 Claude subagents
(`generation_method=claude_subagent_in_session`, exact model version not exposed - recorded in `extra`); `synthetic.py generate` does the same
via the Anthropic API (per-cell checkpoints, backoff). Synthetic rows have **no label, agreement or annotator count**, were not human reviewed
beyond automated checks and a small manual read, and are not human-authored. Set `include_synthetic=false` to build a published-only file.

## Limitations (read before using)
- **Labels are not moral truth.** They are crowd/Reddit-vote/author conventions from specific (largely US, English-speaking, online) populations. Disagreement is real: use `label_agreement`/`label_distribution` where present. ETHICS agreement is a construction floor (>=4/5), not a per-item value. MoralChoice low-ambiguity labels are the authors' design intent, not human verdicts.
- Sampling is label-balanced within sources (e.g. Social Chemistry judgments are near-uniform; natural distributions are skewed to "expected/OK"). Do not infer population base rates from this file.
- DailyDilemmas and MoralChoice (low-ambiguity) text was LLM-generated by their authors; they are marked `llm_generated_published` and may carry LLM stylistic artifacts. DailyDilemmas has no answer key.
- Domain balance: ~50% of items are everyday interpersonal/social-norm items; applied ethics is covered only by the synthetic set; non-English and non-Western sources are scarce (the synthetic set varies setting but is still written by an English-language model).
- Social Chemistry "actions" are annotator-written from rules-of-thumb and can be generic.
- Near-duplicate removal is lexical. Semantic duplicates and items derived from the same Reddit post across Scruples / Social Chemistry / ETHICS-CM-long can remain (the report counts title overlaps); items are not independent samples in that case.
- Licenses: ETHICS, DailyDilemmas, MoralChoice state MIT/CC BY. Scruples, Social Chemistry 101 and MoralExceptQA distributions do not state a data license in the files retrieved here (Reddit-derived text); the manifest says so. Verify before any public redistribution.
- High contamination risk: nearly all sourced items are public benchmarks likely in LLM training data (`contamination_risk` column).
- ~600 records were dropped because identical text carried conflicting labels in the source; this removes some of the genuinely contested items.
